# Notion Block Templates

Custom blocks for Notion, by [Thread & Stack](https://threadandstack.com). Each
folder is a complete, self-contained Notion Worker you can deploy to your own
workspace.

| Template | What it is |
|---|---|
| [`steplist/`](steplist/) | A numbered list of steps under a heading. Change a step's status in place, open a step to read its detail, all in Notion's own colours. |

## Before you start

- **Custom blocks are in Notion's private alpha.** Your workspace needs the
  feature turned on before a deployed block can be inserted into a page.
- You'll need Node 22 or newer and Notion's `ntn` CLI (version 0.23 or newer).

Each template's README walks you through installing, previewing and deploying it.
